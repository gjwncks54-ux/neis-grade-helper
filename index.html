성적 입력 도우미 설치 최신 버전

이 버튼은 실행할 때마다 GitHub Pages의 최신 버전을 불러옵니다. 한 번 설치하면 업데이트할 때 다시 설치하지 않아도 됩니다.

아래 파란 버튼을 브라우저 즐겨찾기 막대로 끌어다 놓으세요. (즐겨찾기 막대가 안 보이면 Ctrl+Shift+B)

성적 입력 도우미

사용법 1: 단계 입력 (교과평가)

통합성적표 양식 지원: 통합성적표 시트의 점수와 기준값을 읽고, 정규 반배정의 새 반·새 번호로 나이스 학생을 맞춥니다.

  1. 나이스 학생평가 > 교과평가 (영역별 평가 또는 교과별 평가)에서 학년·반·교과를 고르고 조회
  2. 즐겨찾기의 성적 입력 도우미 클릭 → 오른쪽에 창이 뜸
  3. 성적 엑셀 파일을 창에 끌어다 놓고 비밀번호 입력 후 열기
  4. 나이스 평가요소와 엑셀 영역 연결 확인 (처음 한 번, 다음부터 기억)
  5. 영역별 기준값 입력 → 인원수와 학생별 결과 확인, 필요하면 학생별로 직접 변경
  6. 나이스에 입력 → 화면 확인 후 나이스의 저장은 직접 누르기
  7. 창은 파란 제목 줄을 끌어서 이동, 오른쪽 아래 모서리를 끌어서 크기 조절, – 버튼(또는 제목 더블클릭)으로 접기. 위치와 크기는 기억됩니다.
  8. 조회를 나중에 했거나 탭·반을 바꿨다면 창의 나이스 다시 확인을 누르세요. (나이스에 입력을 누를 때도 자동으로 다시 확인합니다)
  9. 결과 엑셀 받기 → 단계가 채워진 엑셀이 같은 비밀번호로 잠겨서 내려받아짐

사용법 2: 평어 입력 (학기말종합의견)

  1. 나이스 학생평가 > 학기말종합의견에서 학년·반·교과를 고르고 조회 (예: 1반)
  2. 즐겨찾기 성적 입력 도우미 클릭 → 화면을 보고 자동으로 평어 입력 탭이 열림
  3. 영어반별 평어 엑셀을 여러 개 한꺼번에 끌어다 놓고 비밀번호 입력 후 열기. 한글·워드 표는 복사해서 붙여넣기 칸에 붙여넣기
  4. 이름·반·평어 열은 자동으로 찾습니다. 틀리면 열 바꾸기로 지정 (같은 서식은 다음부터 기억)
  5. 미리보기에서 빨간 줄(동명이인, 이름 오타, 글자 수 초과)만 확인 → 나이스에 입력 → 저장은 직접
  6. 다음 반: 나이스에서 반을 바꿔 조회 → 창의 나이스 다시 확인 → 입력 → 저장. 창 아래에 반별 진행 현황이 표시됩니다.
안심하세요
· 엑셀 파일과 비밀번호는 내 PC 브라우저 안에서만 처리되고 어디에도 전송·저장되지 않습니다.
· 원본 엑셀은 바뀌지 않습니다. 결과는 "_결과.xlsx" 새 파일로 받습니다.
· 나이스 저장 버튼은 누르지 않습니다. 잘못 넣었으면 나이스에서 조회를 다시 누르면 원래대로 돌아갑니다.
· 파일 이름의 (6-2) 같은 반 표시와 나이스 화면 반이 다르면 경고하고, 번호는 같아도 이름이 다른 학생은 입력하지 않습니다.
